DUMMY TEST DATA — NOT REAL BERNESE OUTPUTS
==========================================

The files in this directory (F0/, F1/, F2/) were created by hand to match the
expected format of real Bernese outputs.  They are used only for smoke-testing
the pipeline (python src/run_experiment.py --data-dir data/dummy --no-llm).

None of these numbers come from an actual GNSS processing run.
Do not cite them in results or the README.

Real Bernese outputs go into data/runs/ (created by src/extract.py).
